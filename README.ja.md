# Umidl

**軽量・美しい・高性能な動画ダウンロード / フォーマット変換 / AI 字幕デスクトップクライアント**

ダウンロード + 変換 + 字幕をワンストップで。**Tauri 2 + Rust + Vue 3** で構築し、インストーラは **4.46 MiB**。すべての処理を**本機**で完結します——アップロードなし、登録なし、トラッキングなし。

## 🎯 できること

**「ダウンロード → 変換 → 字幕」の一連の処理を本機で完結**——インストーラは 4.46 MiB（1.8.11 Windows NSIS の実測値）。

| 機能 | 現状（1.8.11。いずれもリポジトリとアプリ画面から確認できます） |
| --- | --- |
| **ローカル処理・アップロードなし** | すべての工程を本機のプロセス内で実行します。アカウントなし、テレメトリなし、クラウドでの解析なし。アンインストールまたはデータディレクトリの削除で状態はすべて消去されます |
| **ダウンロード** | リンク種別に応じて 2 つの経路へ自動ルーティング（yt-dlp によるサイト解析 / aria2c による分割並列）。パート分割・コレクション・HLS/DASH は自動でマージ。一時停止、レジューム、全体の速度制限 |
| **フォーマット変換** | 80 種類の出力フォーマット（動画 22 · 音声 20 · 画像 20 · ドキュメント 18）。可用性は本機エンジンの能力検出によって決まります。docx / xlsx / pptx / odt / ods / odp は純 Rust によるネイティブ解析。NVENC / QSV / AMF のハードウェアエンコードに対応 |
| **字幕** | Whisper.cpp が本機上で文字起こしを実行。認識言語は自動検出 + 8 種類から複数選択でき、「英語に翻訳」トラックを重ねられます。SRT / ASS / VTT / TXT / JSON を書き出し。モデルは 6 段階で必要時にダウンロード |
| **プラグイン** | QuickJS サンドボックス。メモリ 16 MB / スタック 512 KB / 1 回の実行 200 ms というハード上限。ホワイトリスト方式の API（`require` / `process` / `fetch` なし）。プラグインは内容アドレス方式で sha256 を検証 |
| **クロスプラットフォーム** | 同一のソースコードから Windows / macOS / Linux 向けにビルドできます。各プラットフォームの成果物の状態と検証の程度は[プラットフォームサポート](#-プラットフォームサポート)を参照 |

## 🚀 クイックスタート

### Windows（公開済み）

1. [Releases](https://github.com/HuanMoovo/umidl/releases) から `Umidl_x.y.z_x64-setup.exe` をダウンロードします（1.8.11 のインストーラは **4.46 MiB**）
2. 初回起動時に yt-dlp / FFmpeg / Whisper などのランタイムツールを自動検出します。不足しているものは「設定 → 依存ツール」からワンクリックでダウンロードできます（`%APPDATA%/umi-downloader/bin` に導入され、**システム PATH には書き込みません**）
3. リンクを貼り付け → 画質を選択 → ダウンロード開始

### macOS / Linux（ソースからビルド。インストーラは CI が生成）

```bash
git clone https://github.com/HuanMoovo/umidl.git
cd umidl
npm ci

# Linux はシステム依存パッケージを先に導入（CI と同一）
sudo apt-get install -y libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf

npm run tauri:dev      # 開発モード（ホットリロード）
npm run tauri:build    # ローカルでビルド：.dmg / .AppImage / .deb
```

- **CI 成果物の場所**：Actions → `Release` ワークフロー → 該当 run の Artifacts（`umidl-windows-x64` / `umidl-macos-arm64` / `umidl-macos-x64` / `umidl-linux-x64`）。4 プラットフォーム分の成果物は [v1.8.11](https://github.com/HuanMoovo/umidl/releases) に添付済みです。Intel macOS の dmg は arm64 runner 上でのクロスコンパイル製です（コマンドは [CONTRIBUTING.md](CONTRIBUTING.md) 参照）。
- macOS / Linux は現時点で**CI によるビルド成果物のみ**であり、実機での完全な回帰テストは未実施です。aria2 にはこれら 2 プラットフォーム向けの公式な静的パッケージがないため、インストールガイドでは `brew` / `apt` の手順を示します。

### 動作環境（ソースからビルドする場合）

- **Node ≥ 20**、**Rust stable ≥ 1.77**。ほかに Python 3 が必要です（`scripts/` 配下の補助スクリプトの実行に使用）
- Windows：MSVC ビルドツール + WebView2（Win11 は標準搭載）。macOS：Xcode Command Line Tools。Linux：上記の apt 依存を参照

開発の全手順は [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。

## ✨ 機能

### ダウンロードエンジン（2 エンジンの自動ルーティング）
- **aria2c 分割並列エンジン**：直リンク / FTP / BitTorrent トレント / マグネットリンクは 16 接続の動的セグメント（1 ～ 16 で調整可能）を使用し、電源断からのレジュームにも対応します
- **yt-dlp サイト解析エンジン**：1000 以上のサイトの動画、**パート分割とコレクション**、HLS/DASH ストリーミングを自動でマージします
- エンジンは設定で「自動 / yt-dlp / aria2」から指定でき、自動モードではリンク種別に応じてルーティングします
- **全体の速度制限（トークンバケット）**：帯域の上限を設定すると、ゲートウェイ側の絞り込みが yt-dlp、aria2、自身のリクエストに同時に適用され、バックグラウンドでダウンロードしていても閲覧に影響しません
- **管理下の ImageMagick（1.8 で追加）**：ffmpeg では書き出せない形式（PSD/DDS）は、アプリが導入する ImageMagick に任せて処理します。システム PATH は汚しません
- **複数リンク / txt の一括インポート（1.6 で追加）**：複数行のリンクを一度に貼り付けるか txt ファイルを読み込むと一括してキューに投入します。結果パネルには「追加済み / スキップ」と失敗した理由が表示されます
- **マルチスレッドと並列実行（1.6 で追加）**：同時タスク数と、ダウンロードごとの接続数 / セグメント数 / 最小分割サイズを調整できます（aria2 と yt-dlp にそれぞれ適用されます）。範囲外の値は自動的に制限されます
- **ダウンロードキュー**：単一のテーブル形式リストです（V1.8.7 以降、カード表示は廃止され、操作は開く / 保存先を開く / プレビュー / 削除に整理されました)

### プラグインサンドボックス（JavaScript · 1.5 で追加）
- **QuickJS サンドボックスランタイム**：メモリ上限 16 MB、スタック上限 512 KB、1 回の実行時間の予算 200 ms。権限を超えるスクリプトは実際に中断されます（`while(true)` も止められます）。`require` / `process` / `fetch` / ファイル API は注入しません
- **ホワイトリスト方式の機能**：公開するのは `umi.log / resolve / registerResolver / on / retry / storage` のみです
- **リンク解析器**：プラグインが登録した解析器は「このリンクをどのエンジンで処理するか」の判定に参加します。設定ページではプラグインの判断をリアルタイムに確認できます
- **通知フック + 明示的な再試行**：`download:done` / `download:error` / `app:start` イベントがプラグインに通知され、プラグインは `umi.retry(taskId)` を呼び出して失敗したタスクを再試行できます（回数に上限があり、無限に再試行されることはありません）
- **プラグインマーケット（内容アドレスによる検証）**：内蔵のサンプルプラグインをワンクリックでインストールできます。インストール前に **sha256** を照合し、ファイルが 1 バイトでも変更されていればインストールを拒否します
- プラグイン管理画面は **設定 → プラグイン** にあります（1.6 以降、サイドバーの独立ページから移動しました）

### 動画ダウンロード（yt-dlp コア）
- YouTube / Bilibili / Vimeo / TikTok など 1000 以上のサイトに対応
- タイトル、サムネイル、投稿者、再生時間、画質、フォーマットを解析
- 画質の選択や音声のみ（MP3 / M4A / FLAC / WAV / OPUS）の指定を視覚的に操作
- リアルタイムの進捗、速度、残り時間
- **一時停止 / レジューム / キャンセル / 削除**
- サムネイルの埋め込み、字幕の埋め込み、ダウンロード先の指定、速度制限、プロキシ、Cookies

### フォーマット変換（80 種類のフォーマット · FFmpeg + ネイティブ解析 + pandoc/poppler）
- **可用性 = 実際のエンジン能力（1.8）**：カタログ上の 80 種類の出力フォーマットの可用状態は実際の検出（ffmpeg のエンコーダ / マルチプレクサ + ImageMagick のフォーマット表 + pandoc/poppler）によって決まり、本機ではすべて利用可能です。可用性は実際の検出（ffmpeg のエンコーダ / マルチプレクサ + ImageMagick のフォーマット表 + pandoc/poppler）で決まるのであり、固定の表ではありません
- **統一された操作の流れ（1.7 以降は 1 枚のカードに集約）**：ファイル欄 → 単一のフォーマットセレクタ（種別チップ + 検索 + 出力フォーマットのグリッド）→ 種別に応じて表示 / 非表示になるパラメータ欄 → 1 行のエンジン状態バー → キュー。ページの高さは 1.6 より約 64% 減少しました
- **種別のオプション**：すべて / 動画 / 音声 / 画像 / ドキュメントの 5 段階のセグメント選択。グリッドには各フォーマットの可用状態が表示され（本機のエンジンが対応していない場合はグレーアウトし、理由が示されます）、フォーマット名 / 説明による検索にも対応します
- **合計 80 種類**（実機での検出）：動画 22 · 音声 20 · 画像 20 · ドキュメント 18。種別を変えると対応するパラメータパネルに自動で切り替わります（コーデック / 解像度 / CRF は動画・音声の出力先でのみ表示されます）
- **ドキュメント（1.5 で追加）**：docx / xlsx / pptx / odt / ods / odp を **純 Rust のネイティブ解析**により txt / md / html / csv へ変換します（外部ランタイムには依存しません）。pandoc はリッチフォーマット同士の変換（docx·odt·rtf·epub·html·md）を担当し、poppler は PDF のテキスト抽出を担当します。選択するとページ数 / ワークシート / スライド / 文字数が表示されます
- **画像（1.5 で追加）**：PNG / JPG / WEBP / BMP / TIFF / ICO
- 動画：MP4 / MKV / MOV / AVI / WEBM / FLV
- 音声：MP3 / AAC / FLAC / WAV / OPUS / M4A
- コーデック：H.264 / H.265(HEVC) / AV1 / VP9
- 解像度のスケーリング、CRF 品質プリセット、音声の抽出、音声トラックの削除
- リアルタイムのトランスコード進捗とキャンセル

### AI 字幕（Whisper.cpp コア）
- 動画 → FFmpeg で音声を抽出 → Whisper による音声認識 → タイムライン → 書き出し
- 書き出し形式：SRT / ASS / VTT / TXT / JSON
- **認識言語は複数選択が可能（1.6 で追加）**：選択した言語ごとにタスクを 1 つ起動し、「英語に翻訳」を重ねて英語トラックをもう 1 本生成できます
- 言語の自動検出に対応し、中国語 / 英語 / 日本語 / 韓国語 / フランス語 / ドイツ語 / スペイン語 / ロシア語をサポートします
- 6 段階のモデル（tiny 75MB ～ large-v3 3.1GB）を必要に応じてダウンロード

### 内蔵の自動セルフテスト
設定ページの「機能セルフテスト」から完全な回帰テストをワンクリックで実行できます。yt-dlp / FFmpeg / Whisper を実際に呼び出し、ダウンロード、変換、字幕、データ層、設定の読み書きを項目ごとに検証します。

## 🔧 依存ツール

アプリの起動時に自動検出し、不足しているものは「設定 → 依存ツール」からワンクリックでインストールできます（アプリのデータディレクトリにダウンロードされ、システムを汚しません）：

| ツール | 用途 | サイズ |
| --- | --- | --- |

検出順序：**ユーザーが指定したパス → アプリの管理ディレクトリ → メインプログラムと同じディレクトリ → システム PATH**。

## 🆕 機能強化（v1.0.0 強化版）

### インターフェースとテーマ
- **ライト / ダークテーマシステム**：タイトルバーから「ライト / ダーク / システムに従う」をワンクリックで切り替えられ、システムに従う場合は Windows の昼夜に合わせて自動で切り替わります。すべての画面要素は CSS 変数で構成されているため、切り替えは再起動なしで即座に反映されます。
- **6 種類のアクセントカラー**：バイオレット / シアン / 桜ピンク / エメラルド / アンバーゴールド / スカイブルー。アプリ全体の配色（ボタン、プログレスバー、グロー、スクロールバー）が連動して変わります。
- **パフォーマンスの最適化**：
  - 背景のパーティクルは、事前レンダリングしたグロー用テクスチャ + 空間バケットによる線の接続 + 30fps のフレーム制限に変更し、オフ / 3 段階の品質にも対応しています。
  - ダウンロード / 変換の進捗イベントをスロットリング（毎秒 4 回以下）し、高頻度の IPC と画面の再レンダリングを大幅に削減します。
  - タスクカードはサムネイルを遅延読み込みし、コンパクトモードを選択できます。

### 動画ダウンロード
- **サムネイル**：解析後にサムネイルを自動で取得してローカルにキャッシュします（オフラインでも表示可能）。クリックで拡大プレビューできます。
- **個別ダウンロード**：動画 / 音声 / サムネイル / 字幕の 4 つの独立した入口があり、字幕は複数言語の選択に対応します（自動生成字幕のマークを含みます）。
- **プレビューパネル**：大きなサムネイル + タイトル + 投稿者 / 再生回数 / 高評価 / 再生時間 / 公開日 + すべての画質の一覧 + 字幕トラック + 説明文を表示し、ワンクリックでブラウザで開けます。
- **システムプロキシの自動認識**：プロキシを手動で入力していない場合は Windows のシステムプロキシ（Clash / v2ray など）を自動で読み取ります。本機およびイントラネットのアドレスは強制的に直接接続となり、502 を回避します。

### フォーマット変換
- **対応フォーマットの拡充**：動画は 12 種類のコンテナ（mp4/mkv/mov/webm/avi/flv/ts/m4v/mpg/wmv/ogv/gif）、音声は 10 種類（mp3/m4a/aac/flac/wav/opus/ogg/wma/ac3/aiff）。
- **対応エンコーダの拡充**：libx264 / libx265 / libsvtav1 / libvpx-vp9 / ProRes に加え、NVENC / QSV / AMF のハードウェアエンコードを含みます（それぞれに適切なレート制御パラメータを適用します）。
- **フォーマットの自動検出**：ファイルを読み込むと、ソースのコーデックに応じて出力方法を自動で提案します。すでに H.264/AAC であればそのままロスレスで MP4 に格納し、VP9/Opus はロスレスで WebM に格納、可逆圧縮音声は FLAC のまま保持するため、無意味な再エンコードを避けられます。
- **詳細オプション**：映像 / 音声のビットレート、サンプリングレート、チャンネル数、フレームレート、再生速度（0.25x～4x、フィルタチェーンを含む）、ハードウェアアクセラレーションによるデコード、faststart、メタデータの除去、解像度のスケーリング、無音の抽出。

### 設定
- 「外観」ページ（テーマ / アクセントカラー / アニメーションとパフォーマンス）と「既定のパラメータ」ページ（ダウンロードのコンテナ、音声フォーマット、画質の優先設定、ファイル名テンプレート、変換 CRF、自動検出、ハードウェアアクセラレーション、字幕の言語 / フォーマット）を追加しました。
- 通知と動作のスイッチ：完了時のシステム通知、完了後にフォルダーを開く、解析後の自動ダウンロード、元ファイルの保持、速度制限。

### エンジニアリング
- エンドツーエンドのセルフテストモジュールは `selftest` feature のコンパイルスイッチに変更され、**正式リリースのデスクトップクライアントにはセルフテストのコードが含まれません**。開発 / CI では `cargo build --release --features selftest` を使うことで、`--selftest` による全項目の検証を実行できます。
