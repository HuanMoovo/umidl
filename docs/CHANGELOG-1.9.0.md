# Umidl 1.9.0 本地升级说明

基于本机 1.8.11 项目完成的整体升级，适用于 Windows x64。本次更新保留原有技术架构、下载/转换/字幕能力、主题和插件体系。

## 操作体验

- 首页增加“下载视频、转换文件、生成字幕”直接入口；“进行中”会进入实际有任务的模块。
- 下载、转换和字幕页均可直接选择保存目录，简单模式也能使用。
- 插件管理支持按名称、说明、来源搜索，以及按启用状态筛选。
- 转换页选入文件后才展开目标与输出设置；按用途选择即可提取音频，高级参数一键展开，移除重复开关和常驻引擎信息。
- 侧栏在窄窗口收为图标导航，表单自动换行；浏览器预览与桌面状态明确区分。
- 下载、转换和字幕统一使用就地展开的高级选项；简单模式减少背景动效，保留主题配色与高级模式中的动画设置。
- 设置页修正 yt-dlp 文件选择写错配置字段的问题；安装和插件操作防止重复提交。

## 格式转换

- 按当前输入文件和本机转换工具筛选目标格式，图片、音频、视频和文档分别处理。
- 图片不再默认推荐 MP4；表格、Word、PDF 等文档使用各自实际可行的转换路径。
- 选入文件后，常用格式优先显示；可展开更多格式或直接搜索。
- HEIC、HEIF、PSD 等特殊图片按 ImageMagick 的真实读写能力筛选目标。
- 多图层 PSD 导出普通图片时使用合成图，防止生成编号图层后把空文件误报为完成。
- 修复直接复制模式与缩放、变速、采样率或手动码率设置冲突的问题；修改质量预设会采用对应编码设置。
- 转换失败后重试读取原任务保存的参数；旧记录未保存参数时给出提示。
- 提交时预留输出文件名，避免并发任务写入相同输出；PDF 图片导出兼容预留文件。
- 更换、安装工具或主动重新检测后更新格式能力，避免一直使用启动时的旧结果。
- ICO 输出使用真正的图标容器，修复 BMP 内容仅改扩展名的问题。

## 稳定性

- 快速切换链接或文件时，过期的解析结果不会覆盖当前内容。
- 下载、转换和字幕提交期间防止重复创建任务。
- 字幕模型选择、下载及自定义导入处理异步操作期间的新选择，避免覆盖用户之后的输入。
- 离开页面时释放拖拽和相关监听，避免重复响应。
- 部分启动数据加载失败时仍可进入软件，并显示重试入口；恢复监听后同步期间发生的任务变化。
- 设置读取合并重复请求，保存按顺序执行，并保留等待期间的新修改。
- 中、英、日、法四种语言同步补齐新增界面文案。

## 语音转字幕

- 默认继续使用原有 Whisper；按需切换“中文识别”或“云端”，只显示当前引擎需要的设置。
- 新增本地 SenseVoice 与 Paraformer 中文模型，通过 sherpa-onnx 运行；本地音频不会上传。SenseVoice 支持中文、英语、日语、韩语、粤语；Paraformer 使用中文模型。
- 点击“安装引擎与模型”后才下载组件，使用软件独立的 Python 环境。需要本机已有 64 位 Python 3.10–3.13；首次安装需要联网和足够磁盘空间。
- 云端支持可填写地址与模型名称的 Whisper 兼容接口，要求返回真实分段时间戳。远程接口使用 HTTPS；API 密钥只留在本次页面会话，不保存到设置、任务或日志。
- 点击“上传并生成字幕”才发起云端处理；费用由所填服务收取。恢复云端任务时需要重新填写配置并明确提交。
- 本地中文模型生成原文字幕；云端英文翻译仅对兼容的 whisper-1 接口提供。输出支持 SRT、VTT、ASS、TXT、JSON，复用现有任务列表与取消操作。
- 并非任意云端模型都能输出带时间轴的字幕。仅返回纯文本或没有分段时间戳的服务会给出错误，避免生成伪时间轴。
