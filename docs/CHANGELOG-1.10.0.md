# Umidl 1.10.0：语音转字幕服务扩展

在字幕页面选择“云端”后，可从 OpenAI、Groq、Fish Audio、Deepgram、AssemblyAI、Azure Speech、腾讯云、百度智能云、讯飞开放平台中选择服务，并填写对应凭证。自定义 Whisper 兼容接口仍可使用，本地 Whisper、SenseVoice 和 Paraformer 入口保留。

服务商的模型、语言和凭证要求不同，请按界面提示填写。Azure 需要自己的资源地址；百度需要开通支持分句时间戳的极速版接口，具体权限以百度控制台为准。云端识别会向所选服务上传音频，服务可能收费。

凭证仅用于当前会话，不写入任务记录；切换服务商或重试时需要重新填写。长音频按服务限制分块，字幕使用服务返回的时间戳并合并到原视频时间轴。云端任务的英文译文只在支持的接口和模型下提供。

## 使用方法

1. 在“字幕”页面选择视频或音频，并将识别引擎切换为“云端”。
2. 选择服务商，填写其对应的凭证、模型以及必要的资源地址；选择识别语言和字幕格式。
3. 选择输出位置，点击上传并生成字幕。失败后重试时请重新填写凭证。

## 验证范围

前端自动测试、类型检查、生产构建，以及后端自动测试均已通过。各家新增接口的请求、响应、时间戳、错误处理和取消行为以本机模拟服务验证；这并不代表每个厂商的真实账号、余额、地区、模型权限或识别效果已经验证。Groq 的真实短音频测试发生在此前的 1.9.0 兼容接口；Fish Audio 此前测试返回余额不足。其他新增服务尚未用真实账号验收。

平台投稿压制功能按此前要求暂不加入。安装新版本前建议关闭正在运行的 Umidl；安装包不会自动执行。
